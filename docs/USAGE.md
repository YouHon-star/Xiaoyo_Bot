# 使用说明

所有命令都可以**带「小幽」前缀或不带**（私聊全触发，群聊需 @ 或前缀）。
参数之间用 `+`、`＋` 或空格分隔。

> 舞萌账号数据类功能（数据查询出图、账号数据写入）已实现但**闭源**，不在本仓库的说明范围内。
> 需要使用的请先加 bot 好友（QQ `2889487322`）私聊咨询。

---

## 1. 聊天

私聊随便说，群聊 @ 小幽或带前缀。人设由 `LLMCHAT__*` 配置（模型、温度、提示词），
温度建议 ≥ 0.7，太低会退化成「嗯」「哦」。

- 发图片 → `vision.py` 先做客观描述，再交给对话模型
- 同一句话连发 3 遍 → 跟着复读
- 群消息 2% 概率随机发一张收藏表情

## 2. 查询与状态

| 命令 | 说明 |
|---|---|
| `小幽我是谁` | 看自己的 QQ 与权限档 |
| `小幽状态` | 机器人与任务队列状态 |
| `小幽机厅列表` | 机厅报数列表 |

b50 / PC50 等成绩图片由**闭源模块**生成，见第 5 节。

## 3. 娱乐

| 命令 | 说明 |

| `小幽获取歌曲+歌名` | 网易云搜歌并下载（需要本地 `NETEASE_API_URL` 在跑） |

| `ccb` / `查看牛牛` / `查看排行` | 牛牛大作战 |
| `小幽帮助` | 图片版帮助 |

## 4. 管理（仅管理员 / 主人）

```
查看管理            添加管理员+@某人      移除管理员+@某人
拉黑+@某人          解除拉黑+@某人        查看黑名单
添加白名单+群号      白名单列表
开关bot             重启bot
```

- **主人**：唯一 QQ `1923497173`，可开关全局、加/减管理员。
- **管理员**：能拉黑、改白名单、重启 bot。
- 被拉黑用户的消息在入口就被丢弃，不会触发任何回复。
- 群的授权影响高级功能：群未授权时，即使是管理员也按普通档处理（私聊不受限）。

## 6. 常见报错怎么读

| 提示 | 含义 | 怎么办 |
|---|---|---|
| `抱歉您没有权限` | 当前 QQ 或当前群没有对应权限档 | 找主人加白名单 / 换私聊 |
| `你已被禁止使用该功能` | 在黑名单里 | 联系主人 |
| `依赖未就绪` | 闭源模块没部署 | 见第 5 节 |
| `❌ 出图失败` | 静态资源缺失（`storage/maimai/` 没准备） | 按 README 准备资源 |
| 其他异常 | 看服务日志 | `journalctl -u xiaoyo-nonebot -f` |
