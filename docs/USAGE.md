# 使用说明

所有命令都可以**带「小幽」前缀或不带**（私聊全触发，群聊需 @ 或前缀）。
参数之间用 `+`、`＋` 或空格分隔。

> 舞萌账号数据类功能（数据查询出图、账号数据写入）已实现但**闭源**，不在本仓库的说明范围内。
> 需要使用的请先加 bot 好友（QQ `2889487322`）私聊咨询。

## 1. 聊天

私聊随便说，群聊 @ 小幽或带前缀。人设由 `LLMCHAT__*` 配置（模型、温度、提示词），
温度建议 ≥ 0.7，太低会退化成「嗯」「哦」。

- 发图片 → `vision.py` 先做客观描述，再交给对话模型
- 同一句话连发 3 遍 → 跟着复读
- 群消息 2% 概率随机发一张收藏表情

### 拟人化（`humanlike.py`）

`storage/humanlike.json` 调参，改完重启生效：

| 参数 | 作用 | 默认 |
|---|---|---|
| `send.burst_max` / `send.gap_min_ms`~`gap_max_ms` | 一次回几条 / 条间隔 | 3 条、1~3 秒 |
| `send.long_gap_prob` | 换成长间隔（5~10 秒）的概率 | 0.2 |
| `reply.quote` | 回复时引用对方 | 开 |
| `trigger.random_prob` | 群里不 @ 也插话的概率 | 0.06 |
| `context.history_size` / `background_max` | 历史轮数 / @ 时带多少条群背景 | 40 / 12 |
| `risk.per_min` / `per_hour` / `global_per_min` | 每会话每分钟 / 每小时、全局每分钟上限，超了丢多余分段 | 8 / 60 / 20 |
| `proactive.*` | 空闲多久起算、检查间隔、概率、每日上限、静默时段 | 15min、30~90min、0.3、3 次、0~7 点 |

### 黑话 / 梗库（`slang.py`）

从群里自学黑话和群内梗，学到的词会追加进系统提示；用了没人接就冷藏。
`storage/slang_conf.json` 调参，数据在 `storage/slang.json`。

| 命令 | 说明 |
|---|---|
| `小幽黑话` | 看本群能用的词 |
| `小幽黑话预览` | 看此刻会注入给模型的那段原文 |
| `小幽黑话状态` | 词库规模、上次学习时间 |
| `小幽学黑话` | 立刻对当前群跑一轮学习 |
| `小幽黑话加 词 含义` | 手动加，也用来纠正联网考究搞错的领域 |
| `小幽黑话删 词` | 删除 |

采集只看白名单会话（默认取 `storage/mai_modify.json` 的 `tech_groups`），
攒够 10 条 + 5 分钟冷却才跑一轮，最少 2 次出现且 2 人用过才收；
联网考究走 DeepSeek 的 web_search，私聊默认不采集。

## 4. 管理（仅管理员 / 主人）

```
查看管理            添加管理员+@某人      移除管理员+@某人
拉黑+@某人          解除拉黑+@某人        查看黑名单
添加白名单+群号      白名单列表
开关bot             重启bot
```

- **主人**：唯一 QQ `1923497173`，可开关全局、加/减管理员。
- **管理员**：能拉黑、改白名单、重启 bot。
- 被拉黑用户的消息在入口就被丢弃，不会触发任何回复。
- 群的授权影响高级功能：群未授权时，即使是管理员也按普通档处理（私聊不受限）。

## 6. 常见报错怎么读

| 提示 | 含义 | 怎么办 |
|---|---|---|
| `抱歉您没有权限` | 当前 QQ 或当前群没有对应权限档 | 找主人加白名单 / 换私聊 |
| `你已被禁止使用该功能` | 在黑名单里 | 联系主人 |
| `依赖未就绪` | 闭源模块没部署 | 见第 5 节 |
| `❌ 出图失败` | 静态资源缺失（`storage/maimai/` 没准备） | 按 README 准备资源 |
| 其他异常 | 看服务日志 | `journalctl -u xiaoyo-nonebot -f` |
